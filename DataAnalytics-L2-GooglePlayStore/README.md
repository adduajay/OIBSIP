# OASIS INFOBYTE — Unveiling the Android App Market

## Objective
Analyse the Google Play Store ecosystem: data cleaning, category saturation, ratings, installs, pricing and review sentiment.

## Included
- Separate apps and reviews datasets
- Cleaning of installs, ratings, prices, nulls and duplicates
- Category distribution
- Rating distribution and average rating by category
- Size vs installs
- Free/paid and price analysis
- Estimated revenue by category
- TextBlob sentiment classification
- Sentiment by category
- Three developer-focused insights/recommendations

## Run
```bash
pip install -r requirements.txt
python Google_Play_Store_Analysis.py
```
The included datasets are small samples for reproducibility. For the final OASIS submission, replace them with the public Google Play Store Apps and User Reviews datasets and document the source.
