# OIBSIP — Data Analytics

GitHub-ready projects for the OASIS INFOBYTE Data Analytics internship.

## Projects
1. `DataAnalytics-L1-EDARetailSales` — Exploratory Data Analysis on retail sales data
2. `DataAnalytics-L1-CustomerSegmentation` — RFM customer segmentation using K-Means
3. `DataAnalytics-L2-GooglePlayStore` — Google Play Store ecosystem analysis and review sentiment

Each project contains runnable Python code, a notebook, a sample-data generator, README, requirements, and output folders. Replace the sample CSV with the official/public dataset when you want to submit results based on the exact external dataset.
