# OASIS INFOBYTE — Customer Segmentation Analysis

## Objective
Segment e-commerce customers by purchasing behaviour using RFM features and K-Means clustering.

## Included
- Data inspection and cleaning
- Recency, Frequency and Monetary (RFM) features
- Average purchase value
- StandardScaler normalization
- Elbow Method
- K-Means clustering
- Two cluster scatter plots
- Cluster profiling and customer counts
- Marketing actions for each segment

## Run
```bash
pip install -r requirements.txt
python Customer_Segmentation.py
```
If `dataset/online_retail.csv` is absent, a reproducible sample dataset is generated. For final submission, use the recommended public Online Retail dataset and document the source.
