# OASIS INFOBYTE — EDA on Retail Sales Data

## Objective
Perform exploratory data analysis to uncover sales patterns, customer behaviour and actionable business insights.

## Included
- Initial inspection: shape, dtypes, nulls
- Mean, median, mode and standard deviation
- Monthly and quarterly trends
- Age-group and gender analysis
- Top 10 products and category revenue
- Correlation heatmap
- Additional non-obvious insight visualization
- Three actionable business recommendations

## Run
```bash
pip install -r requirements.txt
python EDA_Retail_Sales.py
```
If `dataset/retail_sales.csv` is absent, a reproducible sample dataset is generated automatically. For final internship submission, replace it with your chosen public retail-sales dataset and document its source.
